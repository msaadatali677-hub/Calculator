# 🧮 Calculator | CodeWithSaadat

A simple, modern, and responsive **Calculator Web App** built using **HTML, CSS, and JavaScript**. This project supports basic arithmetic operations, percentage calculations, clearing, deleting, real-time display updates, and keyboard input.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* `%` Percentage calculation
* 🔢 Decimal number support
* 🧹 **AC** button to clear the calculator
* ⌫ **DEL** button to delete the last character
* 🟰 Real-time calculation
* ⌨️ Keyboard support
* 📱 Responsive design
* 🎨 Modern dark UI
* ✨ Button hover and click animations
* ⚠️ Error handling for invalid calculations
* 📐 Mobile-friendly layout

## 🛠️ Technologies Used

* **HTML5** — Structure of the calculator
* **CSS3** — Styling, layout, responsive design, and animations
* **JavaScript** — Calculator logic and keyboard functionality

| Operation      | Symbol |

You can also control the calculator using your keyboard.

| Key         | Function       |
| ----------- | -------------- |
| `0 - 9`     | Enter numbers  |
| `+`         | Addition       |
| `-`         | Subtraction    |
| `*`         | Multiplication |
| `/`         | Division       |
| `%`         | Percentage     |
| `.`         | Decimal        |
| `Enter`     | Calculate      |
| `=`         | Calculate      |
| `Backspace` | Delete         |
| `Escape`    | Clear          |

## 📸 How It Works

1. Click a number button to enter a number.
2. Select an arithmetic operator.
3. Enter another number.
4. Press `=` to calculate the result.
5. Use `AC` to clear everything.
6. Use `DEL` to remove the last character.
7. You can also use your keyboard to perform calculations.
